# Secure Password Manager – Prototype 1

## Overview
This project is the first functional prototype of a secure password manager system.
It demonstrates authentication, encrypted credential storage, and password generation.

## Implemented Features
- User registration and login
- AES-256 encrypted password vault
- Secure password generation
- Modular Java architecture

## Technologies
- Java 17
- AES-256 Encryption
- SHA-256 Password Hashing

## How to Run
1. Compile the project
2. Run Main.java
